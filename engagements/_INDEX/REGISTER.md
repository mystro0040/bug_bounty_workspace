# Engagements Register — what every directory in `engagements/` is

| Directory | Type | What it is |
|---|---|---|
| `_INDEX/` | (dashboard) | This folder — the cross-engagement index + register. NOT an engagement. |
| `_ACCOUNTS/` | (shared resource) | Cross-engagement registry of operator-owned reusable inboxes/personas (identifiers only, no passwords). NOT an engagement. |
| `_TEMPLATE/` | (template) | Blank skeleton copied to start each engagement. NOT an engagement. |

_Kept current by the agent: add a row for each new engagement folder created under `engagements/`._
