# Engagements Index — the cross-engagement dashboard

Open this folder to see all engagements at a glance. NOT tied to any single engagement.
- `ACTIVE.md` — engagements currently in progress (status, phase, last-touched, ⭐ LAST TOUCHED marker).
- `PAST.md` — completed / closed engagements and outcomes.
- `REGISTER.md` — classifies every directory in `engagements/` (real engagement vs. template/example).

The agent keeps these current: whenever an engagement is started, paused, resumed, or closed, it updates
ACTIVE.md / PAST.md / REGISTER.md and the LAST TOUCHED marker.
