# Findings

**Confirmed, PAYABLE findings go here** — one clean report per finding as `<NN_slug>.md`
(e.g. `01_subdomain-takeover-example-host.md`).

Each `<id>.md` contains:
- One-line summary
- Severity + impact
- **Exact, copy-pasteable reproduction steps** (the literal command(s) / HTTP request(s))
- A pointer to the evidence (raw request+response / proof) saved under `05_Exploitation_PoC/` or `06_Proof_of_Concept_and_Impact/`

Only **confirmed, in-scope, high-impact** findings that will survive triage — never leads or hypotheses
(those live in `NOTES.md` / `_NEEDS-REVIEW/`). **An empty `findings/` = nothing confirmed yet.**
