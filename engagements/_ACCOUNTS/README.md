# Shared Accounts Registry (cross-engagement)

Operator-controlled accounts / email inboxes / personas reusable across engagements — the GLOBAL layer,
not tied to one engagement. (Per-engagement tokens/IDs/KYC stay in that engagement's own folder.)

## 🔒 SECURITY — non-negotiable
- Identifiers ONLY. NEVER store plaintext passwords here (operator-memorized or encrypted vault only).
- Bucket-only. NEVER in git or public repos.
- No real member PII / KYC / live session tokens here.
